# Rich Editor: User Guide

This guide explains how to write and format documents with the editor, work with tables and images, save Word files, and use the AI assistant.

> Your organization may have switched some features off, so a button described here might not appear in your toolbar. Shortcuts use **Ctrl** on Windows; on a Mac, use **⌘ (Cmd)** instead.

## 1. The editor at a glance

| Part | What it's for |
|---|---|
| **Toolbar** (top) | Formatting, inserting tables and images, files, AI. On a narrow screen, some buttons move into the **⋯ More** menu at the right end. |
| **Page** (middle) | Where you write. In page view it looks like a sheet of A4 or Letter paper, the same size as a printed or Word page. |
| **Status bar** (bottom) | Word and character count. |
| **Chat panel** (right, when open) | Questions and answers about your document. |

Hover over any toolbar button to see its name and keyboard shortcut.

## 2. Writing and formatting text

Select text, then use a toolbar button or shortcut:

| Format | Button | Shortcut |
|---|---|---|
| **Bold** | **B** | Ctrl+B |
| *Italic* | *I* | Ctrl+I |
| Underline | U | Ctrl+U |
| ~~Strikethrough~~ | S | Ctrl+Shift+S |
| `Inline code` | `< >` | Ctrl+E |
| Superscript (x²) / subscript (H₂O) | x² / x₂ | Ctrl+. / Ctrl+, |
| Text color | **A** with a colored bar | – |
| Highlight | Marker icon | Ctrl+Shift+H (default yellow) |
| Font and size | **Default font** and **11** menus | – |
| Remove all formatting | Tx | – |

**Colors:** pick a color from the palette, choose **Custom…** for any other color, or **None** to remove it.

**Formatting as you type:**

| Type | Result |
|---|---|
| `**word**` | **word** (bold) |
| `==word==` | highlighted word |

**Pasting:** text copied from Word, Google Docs or web pages keeps its formatting (headings, lists, tables, bold and so on); hidden clutter is cleaned away. To paste **without** formatting, press **Ctrl+Shift+V**, or use the **Paste as plain text** button.

## 3. Headings, lists and paragraphs

### Headings

Use the **Normal text** menu to switch between normal text and Heading 1–6. Headings give the document structure and become real headings in Word (they appear in Word's navigation pane).

Shortcuts: **Ctrl+Alt+1** to **Ctrl+Alt+6** for headings, **Ctrl+Alt+0** for normal text.

### Alignment, spacing and indent

| Action | How |
|---|---|
| Align left, center, right, justify | Alignment button, or Ctrl+Shift+L / E / R / J |
| Line spacing (1, 1.15, 1.5, 2…) | Line spacing button (up/down arrows) |
| Indent / outdent a paragraph | Indent buttons, or Ctrl+] / Ctrl+[ |

### Lists

| List | Button | Shortcut | Or type at the start of a line |
|---|---|---|---|
| Bulleted | • list | Ctrl+Shift+8 | `- ` |
| Numbered | 1. list | Ctrl+Shift+7 | `1. ` |
| Checklist | ☑ list | Ctrl+Shift+9 | – |

- Press **Tab** to indent a list item (make a sub-item), **Shift+Tab** to move it back.
- Press **Enter** twice to end a list.
- In a checklist, click the box to tick an item.

### Quotes, code, dividers and page breaks

| Element | Button | Shortcut | Or type |
|---|---|---|---|
| Quote | Quote button | Ctrl+Shift+B | `> ` |
| Code block (with syntax colors) | Code block button | Ctrl+Alt+C | ` ``` ` |
| Horizontal line | — button | – | – |
| Page break | Page break button | Ctrl+Enter | – |
| Special characters and emoji (©, →, €, ✓, 🙂) | Ω button | – | – |

**Pages.** In page view the editor shows where each page ends, like Word: when a paragraph, table or image no longer fits, it moves to the next page and a grey gap labelled **Page 2**, **Page 3** and so on appears above it. You do not have to do anything for this; it updates as you type.

A paragraph, table or image that is taller than a whole page keeps running across the gap. Word will split it when you download the file.

**Page breaks.** To force a new page yourself, press **Ctrl+Enter** or use the **Page break** button. It appears as a dashed line labelled *Page break*, fills the rest of the current page and becomes a real page break in Word and when printing. To remove one, click it and press **Delete** or **Backspace**.

## 4. Links

1. Select the text you want to turn into a link.
2. Click the **link** button or press **Ctrl+K**.
3. Enter the address (you can leave out `https://`), and tick **Open in new tab** if you want.
4. Click **Apply**.

Click a link in the document to see a small menu: **Open link**, **Copy link**, **Edit** or **Remove**.

## 5. Tables

### Insert a table

Click the **Table** button and move over the grid to choose the size (e.g. 3 × 4), then click. The first row is a header row.

- Press **Tab** to move to the next cell and **Shift+Tab** to go back. Pressing Tab in the last cell adds a new row.
- **Column width:** drag the border between two columns.

### Change a table

Click inside a table and a **table menu** appears above it:

| Menu item | What it does |
|---|---|
| **Rows** | Insert row above or below, turn the header row on or off, delete row |
| **Columns** | Insert column left or right, turn the header column on or off, delete column |
| **Merge cells** | First select several cells by dragging across them, then merge them into one |
| **Split cell** | Split a merged cell back into separate cells |
| **Cell color** (paint bucket) | Background color for the current cell or selected cells |
| **Delete table** (trash) | Remove the whole table |

## 6. Images

### Add an image

- Click the **image** button, then **Upload** (click to choose a file, or drag it onto the box) or **By URL** (paste a web address).
- Or drag an image file straight onto the page, or paste a copied image with **Ctrl+V**.

Supported: PNG, JPG, GIF, WebP, SVG and BMP, up to 5 MB unless your organization set a different limit. While an image uploads, it shows **Uploading…**.

### Adjust an image

Click an image to select it:

| Action | How |
|---|---|
| **Resize** | Drag the handles on the sides or corners. The size in pixels is shown while you drag. |
| **Align** | Left, center or right buttons in the image menu |
| **Wrap text around it** | "Wrap text" buttons: image on the left or on the right, with text flowing beside it |
| **Caption** | Type in the **Add a caption…** box under the image |
| **Alt text** | **Alt text** button: a short description for people using screen readers |
| **Original size** / **Replace** / **Delete** | Buttons in the image menu |

## 7. Find and replace

1. Press **Ctrl+F** (with the cursor in the document), or click the magnifier button.
2. Type the text to find. Matches are highlighted and the bar shows e.g. **2 of 7**.
3. **Enter** goes to the next match and **Shift+Enter** to the previous one. **Aa** makes the search match upper and lower case exactly.
4. To replace, type the new text and click **Replace** (current match) or **Replace all**.
5. Press **Esc** to close the bar.

## 8. Saving, downloading and printing

Your document is normally saved by the application you're using (for example with its **Save** button).

The toolbar has one file button, **Download as Word (.docx)**, which downloads the document you are editing as a Word file.

Opening files from your computer, starting a new document and other formats (HTML, Markdown, text, JSON) are still supported by the editor, but they are actions your application decides to offer — for example the sample app's **Open file…** button. Ask your administrator if you need them.

**Word files:**
- **Downloading to Word** keeps headings, fonts, sizes, colors, highlights, lists, tables (including merged cells and cell colors), images with their size, alignment and captions, links, and the page size.
- Word may break lines in slightly different places than the editor. If a reader's computer doesn't have a font, Word uses a similar one.
- **Opening a Word file** keeps the text, headings, lists, tables, images, links, bold, italic and underline, but not font colors or sizes.

**Printing:** click the **printer** button. To save a PDF, choose **Save as PDF** (or **Microsoft Print to PDF**) as the printer.

**Full screen:** the **expand** button fills the screen with the editor; press it again or **Esc** to leave.

## 9. AI assistant

If your organization has turned it on, an **AI** button appears in the toolbar. The AI never changes your document by itself: every change is shown as a **suggestion** that you accept or reject.

### Reading a suggestion

- ~~Red, crossed-out text~~ is what would be removed.
- Green, highlighted text is what would be added.
- Click **Accept** to apply it, or **Reject** to discard it. **Esc** (with the cursor in the document) rejects all open suggestions.
- Accepted changes can be undone with **Ctrl+Z**, like any other edit.

Suggestions aren't saved or exported until you accept them. If you edit the text a suggestion refers to before accepting it, the suggestion is removed so your edit isn't overwritten.

### Change selected text

1. Select a sentence, paragraph or table.
2. A small menu appears under it. Choose:
   - **Ask AI** to type your own instruction (e.g. "make this friendlier" or "turn this into a table"), or
   - **Quick actions** for a ready-made instruction: Improve writing, Make shorter, Make longer, More formal, Translate to Korean, Translate to English.
3. The AI writes its answer (you can press **Stop** at any time), and the suggestion appears in the text.

Only the selected text is rewritten; everything else stays exactly as it is.

**Shortcut:** select text and press **Ctrl+J**.

### Not quite right?

In the purple AI bar above the page:
- **Try again** asks for a different version.
- Type a **follow-up** such as "shorter still" or "keep the second sentence" and press Enter. The AI refines its previous suggestion.

### Other AI actions (AI menu)

| Action | What it does |
|---|---|
| **Generate content…** | Describe what you need ("a project update with a status table"). In an empty document it writes the whole draft; otherwise it adds the new content after the paragraph you're in. **Ctrl+J** with nothing selected does the same. |
| **Continue writing** and **Edit whole document** | Not in the menu. Your application can offer them as its own buttons; ask your administrator. |

### What the AI keeps and what it doesn't

- Bold, italic, lists, tables and links in the rewritten text are kept.
- Font colors, fonts and highlights **inside the rewritten part** may be lost; the rest of the document is untouched.
- Replaced paragraphs keep their alignment, indent and line spacing.

**Always check AI-written text before using it.** The AI can make mistakes.

## 10. Chat with your document

Click **Chat** (the speech-bubble button next to AI), choose **AI → Chat with document**, or press **Ctrl+Alt+J**. A panel opens beside the page.

### Ask questions

- Type a question and press **Enter** (use **Shift+Enter** for a new line), or click a starter such as **Summarize this document** or **List the action items**.
- Answers come from **your document**. If the answer isn't in it, the chat says so.
- Small **numbers** in an answer are **sources**. Click one, or an item in the **Sources** list, to jump to that part of the document; it's briefly highlighted. A crossed-out source means that part has since been changed or deleted.
- Ask **follow-up questions** ("and for Q2?"); the chat remembers the conversation.

### Ask about a specific passage

Select text in the document before asking. The panel shows "Asking about the selected text"; click **✕** if you don't want to include it.

### Change the document from the chat

Ask for a change, e.g. "Make the introduction more formal and add a risks section". The chat explains what it changed, and the changes appear in the document as suggestions. Use **Accept** or **Reject** in the chat message, or on each suggestion in the document.

### Use an answer

Under each answer:
- **Copy** copies the answer, without source numbers.
- **Insert in document** adds the answer after the paragraph you're in (as a suggestion to accept).
- **Replace selection** (shown when text is selected) replaces the selected text with the answer (as a suggestion).

### Other controls

- **Stop** interrupts an answer that's being written.
- **Clear chat** (trash icon) starts a new conversation.
- **✕** or **Esc** closes the panel.

Depending on your application, the conversation may be kept with the document and come back when you reopen it. Sources from an earlier session are shown, but can't be clicked.

Very long documents (more than about 60 pages) are only partly searched, and the answer tells you when that happens.

## 11. Version history

Each time you accept an AI change, the editor saves a copy of the document as it was just before.

1. Open **AI → Version history**.
2. Each entry shows what happened next (e.g. "Before: Make shorter") and when.
3. Click **Restore** to go back to that version. Your current document is saved as a version first, so you can switch back.

Version history lasts until you close or reload the page, unless your application keeps it longer.

## 13. Tips and common questions

**A toolbar button is missing.**
It may be in the **⋯ More** menu at the right end of the toolbar (narrow windows), or your organization may have turned the feature off.

**I pressed Ctrl+F and the browser's search opened.**
Click inside the document first, then press Ctrl+F.

**Ctrl+A selected only one table cell.**
Inside a table, Ctrl+A selects the current cell. Click in normal text first to select the whole document.

**My image won't insert.**
Check the file type (PNG, JPG, GIF, WebP, SVG, BMP) and size (5 MB by default). A message explains what went wrong.

**The AI says "The AI request failed".**
Check your connection and click **Try again**. If it keeps happening, contact your administrator.

**The AI suggestion disappeared.**
You edited the same text while the AI was writing, so the suggestion was discarded to protect your edit. Ask again.

**The Word file looks slightly different from the editor.**
Word lays out text on its own, so line breaks can move a little, and missing fonts are replaced. Content and structure are the same.

**Is my document private when I use AI?**
When you use AI or chat, the relevant text (for chat, the whole document) is sent to the AI service your organization has set up. Follow your organization's rules about what may be sent.
